# 👋 Hey, I'm Walter

### Software Engineer | Backend & Distributed Systems | .NET & Go | Cloud & AI

I build **backend systems, APIs and distributed applications** with a focus on scalability, reliability and clean architecture.

I'm particularly interested in **.NET, Go, distributed systems, cloud infrastructure and AI-powered applications** — from designing APIs and asynchronous workflows to containerized deployments and production-ready services.

### 🚀 What I Work With

* ⚙️ **Backend:** .NET, C#, Go, Java, Kotlin, Python
* 🌐 **APIs & Services:** REST, microservices, asynchronous processing
* 📨 **Distributed Systems:** RabbitMQ, messaging, event-driven architectures
* ☁️ **Cloud & Infrastructure:** AWS, Docker, Kubernetes, Linux, Nginx
* 🤖 **AI / ML:** Python, TensorFlow, Keras, AI integrations
* 🗄️ **Databases:** PostgreSQL, SQL Server, MySQL, MariaDB
* 🎨 **Frontend:** TypeScript, JavaScript, Vue.js, Flutter
